# Spec lock

**Owner:** designer / researcher. **Gate:** `spec-lock-pass`.

1. Scout prior art with `oss-scout-gate`: adopt, skill, build, or skip. Do not rebuild what exists.
2. Write the spec: goal, users, requirements as testable statements, non-goals, failure states, tunable numbers with defaults, locked vs open decisions.
3. Recommend an answer for every open question. Do not hand the human a blank choice.
4. Run `spec-lock-pass`. Fix every fail.
5. Get sign-off. Record who approved and when.

A locked spec changes only through this stage again.
