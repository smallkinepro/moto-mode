# Retro

**Owner:** designer / researcher. **Gate:** `skill-evolution-after-failure`.

Trigger: a human correction, a failed gate on a second attempt, or a workaround that should become standard.

1. Name the failure class as a mechanism, not a symptom.
2. Find the skill or rule that should have caught it (`specialty-skill-tree`).
3. First occurrence: add a checklist bullet. Repeat: add or extend a deeper skill.
4. Re-run `agent-skill-spec-check` on changed skills.
5. The next similar task's handoff must name the updated skill. That is the proof the loop closed.
