# seats

Role templates for an agent team. Copy one into your agent's system prompt or project instructions and fill the brackets. Every seat follows `skills/agent-design-bar`: one job, a voice, anti-jobs, a verify path, and minimal tools.

| Seat | One job |
|---|---|
| [chief-of-staff](chief-of-staff.md) | Route work, hold priorities, carry approvals |
| [designer-researcher](designer-researcher.md) | Specs, prior art, rules, and skills |
| [builder](builder.md) | Ship code that passes its gates |
| [data-engineer](data-engineer.md) | Trustworthy pipelines and models |
| [reviewer](reviewer.md) | Independent verification |
